# Expense Tracker

A simple expense tracker app made with HTML, CSS, and JavaScript.

## Features

* Expense and income tracker
* Easy to see balance, income, and expenses
* Ability to delete transactions
* Easy and clean UI
* Save data with local storage
* Works offline


## Getting Started

1. Clone or download the repository.
2. Open the folder on your computer.
3. Open `index.html` with your preferred browser.

No installation or extra setup is needed.

## How to Use

To add income, type a description of where it is coming from and enter a positive number for the amount.

Example:

```text
Description: Salary
Amount: 5000
```

To add an expense, do the same thing but enter a negative number for the amount.

Example:

```text
Description: Food
Amount: -200
```

The balance, income, expenses, and transactions will automatically update after you add or delete a transaction.

## Storage

Your transactions are saved in your browser using LocalStorage. This means your data will remain saved after refreshing the page or closing and reopening the browser.

> Note: Clearing your browser's site data or LocalStorage will remove your saved transactions.
